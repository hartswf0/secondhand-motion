Cartoon Archive Index

Any shot in the Moving Image Archive should be able to play as a moving doodle cartoon. Each shot becomes one file: camera, depth planes, doodles, the character's keys and an exposure sheet. Every page here is a view of files like that.

Works, in the order they were made

The loop every change goes through

StateThe shot file: camera pan, planes, doodles, keys, x-sheet.
ObservationFootage frames, SAM silhouettes, measured camera, real doodles to match.
ProposalThe agent keys a pose, picks or draws a doodle, places a plane.
ValidatorMeasured tests, structural tests, then a blind critic who never sees the builder's reasoning.
EventAccepted revision written back to the shot file; the page re-renders from it.

Tests

Run on Giraffe Walks Past, version 2. Measured tests are computed from the shot file, structural tests check the file and the page, and judged tests need an independent viewer. A bar is never lowered to make a test pass.

TestResultBarStatusHow it is measured
A test can pass by measuring nothing

The first foot-slide test found zero planted frames and reported a pass. It now fails when it has fewer than four planted intervals to measure.

A number can pass while the drawing gets worse

Forcing one leg length made the proportion test pass and crumpled the legs in frames 1–3 and 30–33. Every numeric pass is followed by looking at the frames.

The classifier alone is a misleading reward

It accepts traced silhouettes as giraffes. Recognition is scored together with typicality and pose fit, and the critic outranks all three.

How the work is kept

Every deliverable is an HTML page

Datasets, experiments and shots are published as pages you can open on a phone. Raw files stay in the workspace as sources, not as the delivered form.

Each page carries its own data

The shot file or dataset is embedded in the page that shows it, so a page can be re-rendered or forked without the session that made it.

Every drawing names its source

A Quick, Draw! key_id, or a note that the agent drew it and why no real doodle fitted.

Reviews are kept, not summarised away

Each shot page records its critic rounds: verdict, the gap named, and the repair that followed.
