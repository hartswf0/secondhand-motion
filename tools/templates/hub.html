Putting a new lot on the rack

A lot is one folder with an item.json. The rack, the stage counts and the test rack are built from those files, so adding work never means editing this page.

python3 tools/new_subject.py "cow" --wave 3   # scaffold shots/cow/
# an agent works the lot with AGENTS.md
python3 tools/import_batch.py batches/<new> traced/<new>.json
python3 tools/validate.py                       # every lot checked
python3 tools/build_pages.py                    # rack rebuilt

A new test is one entry in tests/registry.json: id, bar, how it is measured, the stage it guards. Mark it planned until a script computes it; every lot then shows it as not run until it does.
